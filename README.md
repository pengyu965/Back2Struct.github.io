# Back2Struct — Project Page

Static project website for **Back2Struct: Making Structured Images Editable Again**.
Plain HTML/CSS/JS, no build step. Deploys as-is to GitHub Pages.

## Files
```
index.html                 # the page
static/css/style.css       # styles (self-contained; Google Fonts via CDN)
static/images/             # web PNGs (generated by convert_figs.sh)
convert_figs.sh            # renders the paper's figure PDFs -> static/images/*.png
```

## 1. Generate the figures (one time)
Browsers can't display PDFs as images, so render the paper PDFs to PNG on a machine
that has `pdftoppm` (poppler), ImageMagick, or Ghostscript. Run from this folder:

```bash
bash convert_figs.sh            # reads ../figs and ../supplementary_figs by default
# or point elsewhere:
FIGS=/path/to/figs SUPP=/path/to/supplementary_figs DPI=240 bash convert_figs.sh
```

Until you run it, each figure shows a small "run convert_figs.sh" placeholder — the
text and result tables render fine regardless.

## 2. Add the paper PDF (optional)
Drop your compiled PDF at `static/Back2Struct.pdf` so the **Paper** button works.

## 3. Preview locally
```bash
python3 -m http.server 8000     # open http://localhost:8000
```

## 4. Deploy to GitHub Pages
Copy the **contents** of this folder to the root of `pengyu965/Back2Struct.github.io`,
commit, and push. Then enable Settings → Pages → deploy from `main`/root.
Served at `https://pengyu965.github.io/Back2Struct.github.io/`.

## Notes
